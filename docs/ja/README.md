# OER Client — 利用者向けドキュメント

`local_oerclient` は**あなた自身の Moodle サイト**にインストールし、別の
場所にインストールされた中央 OER Exchange(`local_oerexchange`)と接続する
プラグインです。コースやアクティビティを Exchange の公開カタログへ共有したり、
他の教員が共有したものを閲覧したり、自分のサイトへリソースをインポートしたり
できます。

アーキテクチャや実装に関する情報は、開発ワークスペースのプラットフォーム設計
資料(`dev-docs/oer-platform/DESIGN.md`)を参照してください。本書は開発者向け
ではなく、プラグインを**利用する**方向けのドキュメントです。

## サイト管理者向け: Exchange への接続

これは Moodle サイトごとに一度だけ行う初期設定です。

1. **サイト管理 ▸ プラグイン ▸ ローカルプラグイン ▸ OER Client** を開き、
   **Exchange URL** に接続したい Exchange サイトを設定します
   (例:`https://oer-exchange.example`)。
2. **サイト管理 ▸ プラグイン ▸ ローカルプラグイン ▸ OER Client ▸
   Exchange に登録する** を開きます。連絡先メールアドレスを入力して
   送信します。これにより Exchange 側へ登録リクエストが送られます —
   この時点ではまだ何も使えません。
3. **承認を待ちます。** Exchange 側の管理者がリクエストを確認し承認します
   (これは先方での手動対応であり、明確な所要時間はありません)。承認
   されると、入力した連絡先アドレスに**サイトトークン**がメール送信
   されます。
4. 同じ設定画面の**サイトトークン**欄にそのトークンを貼り付けます。これで
   サイトの接続は完了です — 教員は共有・インポートができるようになります。

接続後は 2 つのケーパビリティで権限が制御されます:
`local/oerclient:share`(コース/アクティビティの共有 — 既定で編集可能な
教師と管理者に付与)と `local/oerclient:import`(リソースのインポート —
既定は同様)。

## 教員向け: アカウントの連携

Exchange 上での共有・レビューは、このサイトへのログインとは別の、個人の
Exchange アカウントに紐づけられます(連携プロセス自体は Exchange への
ログイン・サインアップを使うため、以前に Exchange を直接利用したことが
あれば同じアカウントになることもあります)。

`/local/oerclient/index.php` にアクセスし、**Exchange アカウントを連携する**
をクリックします。Exchange 側でログインまたは新規登録を行うと、自動的に
このサイトへ戻ってきます — この操作は一度だけで済みます。アカウントを
連携するまで共有はできません(閲覧・インポートには影響しません)。

## 教員向け: コースまたはアクティビティの共有

1. 共有したいコースを開きます。**Share to OER Exchange(OER Exchange へ共有)**
   はセカンダリナビゲーションの最上位タブにはありません — 編集権限が
   あれば、**More ▾(その他)** をクリックして開くメニューの一番下に
   表示されます。
2. ウィザードに入力します。
   - **タイトル** — コース/アクティビティ名から自動入力されますが、
     必要に応じて編集できます。
   - **概要** — 何のためのものか、対象は誰かを記述します。
   - **言語**、**タグ** — 他の教員が見つけやすくなります。
   - **ライセンス** — クリエイティブ・コモンズ(またはパブリックドメイン)
     のいずれかを選択します。必須です。
3. **共有する** をクリックします。これは即時には完了しません — 裏側では、
   コースの内容にかかわらず**学生や個人情報を一切含まない**サニタイズ
   済みバックアップが作成され、Exchange へアップロードされます。ステータス
   ページに遷移し、進行状況が更新されます: *キュー待ち → サニタイズ
   済みバックアップの作成中 → Exchange へアップロード中 → 公開完了*
   (エラーが発生した場合は *失敗* とエラーメッセージが表示されます)。
   公開が完了すると、Exchange 上で確認するためのリンクが表示されます。
4. コース全体ではなく**単一のアクティビティ**を共有する場合も同様です:
   そのアクティビティを開き、アクティビティ自身のセカンダリナビゲーション
   にある **More ▾(その他)** をクリックすると、一番下に
   **Share to OER Exchange** があります。ウィザードの**タイトル**欄には
   (コース名ではなく)そのアクティビティ自身の名前が自動入力されるので、
   コース全体ではなくアクティビティを共有していることが確認できます。

すでに共有済みのコースを更新後に再度共有すると、重複したエントリを作る
のではなく、同じカタログのエントリに新しいバージョンとして追加されます。

## 教員向け: 閲覧とインポート

1. **Browse OER Exchange(OER Exchange を閲覧)**を開きます
   (`/local/oerclient/index.php` またはコースナビゲーションから)。
   Exchange 本体と同じようにカタログを検索できます。
2. リソースをクリックしてプレビューします: ライセンス、構造(セクションと
   アクティビティ)、必要なコントリビュートプラグインが自分のサイトに
   すでに入っているか、または不足しているかがわかります。
3. **Import(インポート)** をクリックします。
   - **コース全体**: 自分のサイトに新規コースを作成し(学生に見せる前に
     内容を確認できるよう既定で非表示)、内容をインポートした後、
     ローカライズ・チェックリストのページに移動します。
   - **単一のアクティビティ**: どのコースにインポートするかを選択します
     (インポート権限があるコースのみが一覧に表示されます)。選択した
     コースに追加されます。
4. インポートはリストア処理を同期的に実行します — 通常の Moodle の
   「処理中」の待機画面の後、チェックリストのページに到達します。大きな、
   あるいは特殊なバックアップは、まれに Moodle のリストア事前チェックに
   失敗することがあります。その場合は中途半端にインポートされたコースが
   残るのではなく、エラーが表示されます。

## インポート後のローカライズ・チェックリスト

インポートが完了すると、学生に使う前に確認しておきたい項目の簡単な
チェックリストが表示されます — サイト固有の警告ではなく、一般的な確認
事項です。

- **日付**: アクティビティの締切日やコース開始日は元のコースのものが
  引き継がれており、自分の学期に合わせて更新が必要な可能性が高いです。
- **名前や参照情報**: 元のコースに含まれていた氏名、所属機関、連絡先
  情報がアクティビティの内容に残っていないか確認してください。
- **公開設定**: インポートされた**コース**は、まず内容を確認できるよう
  意図的に既定で非表示になっています — 準備ができたらコースを公開して
  ください。
- **採点**: 特に元の作成者と異なる採点方式を使っている場合、成績項目や
  尺度が自分の成績表の設定と一致しているか確認してください。

## プライバシーとデータの取り扱い

このプラグインは以下を保存します: 個人の Exchange アカウントへのリンク
(Exchange 上であなたとして操作するためのトークンを含む)、共有した
内容とそのステータスの記録、インポートした内容とインポート先コースの
記録。これらはすべて本プラグインの GDPR プライバシープロバイダーの
対象です — エクスポートや削除には Moodle 標準の**サイト管理 ▸
ユーザー ▸ プライバシーとポリシー ▸ データリクエスト**機能を利用して
ください。

共有時に学生などの個人情報がアップロードされることはありません —
共有される全てのバックアップはユーザーデータを明示的に除外して作成
され、公開前に Exchange 側でもサーバー側で独立して再検証されます
(多層防御:自サイトでサニタイズし、Exchange 側でも再確認します)。

## トラブルシューティング

- **「Share to OER Exchange」リンクが表示されない** — コースの編集権限
  が必要です。また、このサイトが Exchange に接続されている必要があります
  (上記参照)。
- **共有ステータスが「キュー待ち」のまま進まない** — この処理はサイトの
  スケジュールタスク(cron)で実行されます。cron が定期的に実行されて
  いない場合、共有処理が遅延します。サイト管理者に確認してください。
- **共有に失敗した** — ステータスページにエラー内容が表示されます。
  よくある原因: まだ Exchange アカウントを連携していない、または
  バックアップが Exchange の許容する最大サイズを超えている、などです。
- **インポートボタンが表示されない、または無効になっている** — 単一
  アクティビティの場合、少なくとも 1 つのコースでインポート権限が
  必要です。候補がない場合は、適切なコースへのアクセス権を管理者に
  依頼してください。
- **必要なプラグインの横に「未インストール — スキップされます」と表示
  される** — そのアクティビティタイプが自分のサイトで利用できません。
  インポート自体は可能ですが、そのアクティビティだけは結果に含まれ
  ません。必要であれば先にプラグインをインストールしてください。
